## Public hosting

| URL | Host |
|---|---|
| `*.vercel.app` then a custom domain | Vercel Hobby (primary, HTTPS, CDN) |
| `https://chinaharry23.github.io` | GitHub Pages (static export of the same repo) |

`xinlongbao.com` is **already registered** (since 2013, registrar Gname, expiry 2027). It cannot be created on Vercel Hobby. Nearby names that looked free: `xinlong-bao.com`, `harrybao.com`, `xinlongbao.dev`.

Hobby hosting is $0. A new `.com` is roughly registrar cost (~US$10–15/year) if you buy it on [vercel.com/domains](https://vercel.com/domains). Point it at the Vercel project; leave GitHub Pages on `chinaharry23.github.io` as the mirror.

Do not publish DGL, `Private/`, or HTB material.
