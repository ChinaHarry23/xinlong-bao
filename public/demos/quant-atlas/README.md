# Quant Atlas

Static interactive study site for learning quant top-down:

- `Intro to Quant`: what quant is, the closest "ChatGPT moment", and the current frontier stack
- `Beginner`: the first six modules that matter
- `Practice / Simulation`: quiz + edge-vs-friction simulator
- `Master`: specialization map and primary sources

## Open it

Open [index.html](/Users/chinaharrymacs/Desktop/Workspace/Codex_pg/Quant_study/index.html) directly in a browser, or run a quick local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
